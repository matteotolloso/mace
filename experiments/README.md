# Experiments

One folder per experiment, named `<dataset>/<model>-<uq>/<protocol>`; that path is the
experiment id used by every `uq` command (legacy letters work too: `uq show D`).

```text
<id>/experiment.yaml     what to run: dataset, protocol, parent, splits, members, evaluation steps
<id>/config.yaml         MACE hyperparameters (paths are added by `uq train-member`)
<id>/evaluation/         five-split aggregates (*.csv, *.svg) — tracked, cite these
<id>/evaluation/split_<s>/   per-split outputs of every evaluation step — tracked, GPU-costly
```

Heavy artifacts are in `runs/<id>/split_<s>/` (git-ignored). Schema, training and
how to add an experiment: [docs/experiments.md](../docs/experiments.md); what each
output shows: [docs/evaluation-outputs.md](../docs/evaluation-outputs.md).
